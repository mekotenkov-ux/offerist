# Происхождение методик

Плагин содержит заново сформулированное компактное ядро. Установочные команды, код сторонних runtime, клиентские PDF и исходные архивы не входят в дистрибутив. Личная карта источников с точными путями хранится только в проекте разработки.

| Исследованный материал | Что перенесено |
|---|---|
| Учебные архивы GSC, Яндекс, Ahrefs, Keys.so, семантики и SF | Выбор источника по вопросу, сравнимость срезов, пропуски, ограничения, чтение экспортов |
| Предоставленный набор аудит-агентов | Приоритет влияния на результат, подтверждение проблем, SF как дополнительная проверка |
| Существующий агент предпродажного GEO-аудита | Разделение retrieval, источника, цитирования и упоминания; знаменатели; протокол замера |
| commercial-proposal-builder, presentation-html-pdf, система слайдов ResultUP | Доказательства и решение; смета после обоснования; один вывод на слайд; визуальная QA |
| Обучение SEOMEAT Убийца Копирайтеров | Профиль, происхождение правил, пробный запуск, обратная связь, области применения |
| Исторический пример КП и последующая обратная связь | Историческая методика переработана: конкретные изменения, механизм влияния, объёмы и ресурс. В слепом тесте эталон и производные исключены; цели подрядчика не приписываются клиенту |
| [Пост о поведенческом анализе](https://t.me/seokotenkov/29) | Сравнение длинных визитов по устройствам как диагностика; пороги автора не норматив |

Цены, лимиты и API-схемы учебных источников не являются текущим контрактом поставщиков. При подключении инструмента используйте его актуальную документацию и реальный ответ. Числа, кейсы и гарантии из примеров не перенесены как общие правила.

[Упаковка плагинов OpenAI](https://developers.openai.com/plugins/build/plugins) проверена 2026-09-24: переносимый корневой manifest и совместимый Codex manifest. Доступность установки и инструментов проверяется в среде пользователя.
