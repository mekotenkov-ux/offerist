# Офферист

Полный пакет из 19 скиллов для SEO/GEO коммерческих предложений. Свободный помощник автора, брифовка, быстрый аналитический Word и полный процесс с Продавцом доступны отдельно.

| Вход | Назначение |
|---|---|
| [offerist](skills/offerist/SKILL.md) | Выбор маршрута |
| [offerist-assistant](skills/offerist-assistant/SKILL.md) | Вольная совместная разработка КП |
| [offerist-brief](skills/offerist-brief/SKILL.md) | Переписка и брифинг |
| [offerist-quick](skills/offerist-quick/SKILL.md) | Готовый Word по аналитическому формату |
| [offerist-setup](skills/offerist-setup/SKILL.md) | Профиль агентства, обучение и память |
| [offerist-seller](skills/offerist-seller/SKILL.md) | Полный процесс и итоговое КП |

Все специалисты находятся в skills. [Этапы](skills/offerist/references/stages.md), [локальные сборщики](docs/connectors.md), [workflow](docs/workflow.md).

Открытый дистрибутив: https://github.com/mekotenkov-ux/offerist. В корне репозитория — русское руководство, каталог всех скиллов, установка и вымышленные примеры. Синтетический Word включён в быстрый скилл как образец формы; его данные и цены не являются условиями нового клиента.
