# Проверки и ограничения выпуска

Текущий выпуск: [1.3.0-sources.1](release-1.3.0.md). 33 офлайн-теста прошли, включая 28 новых регрессий контракта источников. Проверяется также общий валидатор репозитория: состав, ссылки, версии и отсутствие частных исходников. Проверка реальных API и клиентская приёмка не являются результатом этих тестов. Исторические результаты ниже относятся к указанным прежним выпускам.

## Историческая проверка 1.0.4 от 6 октября 2026

Публичный комплект 1.0.4-portable.1 основан на установленном 1.0.3-quick.1. Python-ядро полного workflow и сборщики перенесены без изменения; кандидат rc2 не развёрнут. Изменения касаются переноса, документации, синтетического референса и инструментов установки/проверки.

Выпуск проверяется офлайн: манифесты и marketplace, наличие 19 скиллов и ресурсов, YAML, относительные ссылки, отсутствие клиентского документа/локальных путей/credential-файлов, установка в новый каталог и сохранение связей, арифметика примеров. Генератор учебного Word использует данные примера; документ рендерится и просматривается после последней правки. Результаты доступны в CI после загрузки.

Учебные данные и примеры ревью не являются живым API-тестом, независимым прогоном агента или пользовательской приёмкой КП. Возможности конкретного агента, доступ к источникам и коммерческие условия проверяются при его настройке. Полная историческая регрессия ядра не выдаётся за новый прогон этого выпуска.

Локальные команды:

```bash
python -m pip install -r requirements-dev.txt
python tools/validate_repository.py
python -m unittest discover -s tests
```

Для повторной сборки учебного Word установите `requirements-examples.txt` и запустите `python tools/build_demo.py`. PDF нужно повторно экспортировать доступным Word/LibreOffice и визуально проверить; скрипт не объявляет эту проверку выполненной автоматически.
