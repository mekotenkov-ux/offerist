# Старт полного процесса и передача результата

Учебный запрос:

```text
$offerist-seller Подготовь полное SEO-КП для example.org.
Это учебный комплект: не делай сетевые запросы и не называй пример живым аудитом.
GEO не включаем. Используй доступные файлы, покажи незакрытые части охвата.
Смету заполняет человек; реальных ставок и кейсов не предоставлено.
```

Продавец фиксирует scope и запускает доступную часть исследования. Для полного принятого результата необходимы результаты всех выбранных узлов; этот короткий пример не изображает полностью заполненные двадцать выходов.

Пример передачи аналитики:

```json
{
  "stage": "analytics",
  "status": "partial",
  "source": "examples/demo/pages.csv",
  "period": "2026-09",
  "scope": "6 учебных URL; две поисковые системы",
  "findings": ["Яндекс 340, Google 235, органика 575"],
  "limitations": ["Данные синтетические", "Нет фактического поведенческого отчёта"],
  "next_action": "Запросить разрешённую выгрузку поведения для реального проекта"
}
```

Для настоящего workflow используйте схемы узлов и реальный журнал файлов. `complete` относится к проверенной стадии, не к успеху сделки. Независимый reviewer получает фактический клиентский пакет в чистом контексте; автора нельзя переименовать в независимого Клиента.
