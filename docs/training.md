# Настройка обучение и память

Обучение Оффериста означает настройку профиля, работу с разрешёнными примерами и сохранение правил обратной связи. Оно не меняет веса модели и не создаёт память без файлов или другого доступного хранилища. Используйте `$offerist-setup` для одного явно выбранного агентства.

## Что стоит передать

| Область | Материал | Что сохраняется |
|---|---|---|
| Агентство | Позиционирование, услуги, исключения, типовые клиенты | Подтверждённые факты и границы предложения |
| Экономика | Ставки, правила оценки, внешние расходы или выбор сметы для человека | Цены с источником/датой либо незаполненные ценовые поля |
| Внедрение | Кто готовит контент, публикует, разрабатывает и принимает | Ответственность и зависимости |
| KPI | Определения целей, baseline, окна измерения, условия бонуса | Согласованные правила; не примерные обещания |
| Опыт | Кейсы с исходной точкой, работами, результатом и разрешением на показ | Проверяемые карточки, допустимые формулировки |
| Результаты работ | Примеры ТЗ, отчётов, постановок задач и материалов | Что конкретно получит клиент; редактирование перед показом |
| Стиль и форма | Разрешённые КП, референсы и комментарии к ним | Правила подачи, структура, плотность и критерии проверки |

Стандарт B2B доступен сразу и не требует старых КП. Особый формат изучается по явному запросу. В свободном режиме форму определяет человек; профиль агентства не должен превращать каждую задачу в обязательный шаблон.

## Обучить стилю

```text
$offerist-setup Разбери эти разрешённые КП как образцы подачи.
Сохрани наш тон, структуру аргументов и способ объяснения работ.
Отдели стиль от фактов клиентов и старых цен. Покажи извлечённые правила,
потом проверь их на небольшом новом фрагменте.
```

Агент выделяет типы блоков, длину и плотность текста, тон, способ связывать факт с действием, оформление таблиц и правила формулировки условий. У каждого правила источник. Спорные выводы остаются предложенными до подтверждения. Кейсы, цены и показатели образца не становятся текущими фактами агентства.

Для презентационного стиля можно передать разрешённую презентацию и попросить извлечь шрифты, сетку, плотность, цвета и типы слайдов. Офферист хранит требования; создание/рендер презентации выполняются доступными инструментами среды. `offerist-presentation` превращает уже обоснованное КП в презентацию, не заменяет исследования.

## Замечания и область действия

Сначала правка применяется к текущему КП и связанным расчётам. Затем определяется область: `agency` — правило всех предложений агентства; `project` — особенность клиента; `run` — только этот документ/запуск. У правила есть цитата человека, источник, формулировка, проверяемое условие и статус `active` или `proposed`.

Пример: «Не расписывай каждый будущий месяц — после первого цикла ведём живую очередь». Это может быть правилом агентства, если человек так указал; требование одного клиента не становится общим автоматически. Отозванное правило исключается из активного контекста, история остаётся для понимания изменений.

## Локальные команды памяти

Из корня скачанного репозитория, для нового частного рабочего хранилища:

```bash
python plugins/offerist/scripts/offerist.py --store .offerist init-profile demo --name "Моё агентство"
python plugins/offerist/scripts/offerist.py --store .offerist feedback demo --input plugins/offerist/examples/feedback.json
python plugins/offerist/scripts/offerist.py --store .offerist context demo
```

`feedback.json` — учебный файл. Перед реальной записью замените его реальным указанием человека; не выдавайте пример за принятое предпочтение. Для отмены используйте `retire-rule` с ID сохранённого правила и причиной; `--help` показывает точные параметры. `init-profile` не перезаписывает существующий профиль.

Хранилище `.offerist` исключено из Git. Профили разных агентств и факты клиентов изолируются. При переносе передавайте только разрешённый профиль/экспорт, а подключение ключей настраивайте заново. Установка нового плагина не переносит частную память. [Учебный профиль](../examples/agency/profile.md), [схема локальной памяти](../plugins/offerist/skills/offerist/references/runtime.md).
