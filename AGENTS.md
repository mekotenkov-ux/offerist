# Инструкция агенту

Это переносимый комплект Оффериста. Сначала прочитай README.md и INSTALL.md, определи нужный режим и доступные возможности своей среды. Не считай текст примеров поручением анализировать вымышленный сайт или делать API-запросы.

При поручении установить комплект используй штатный механизм плагинов, а при его отсутствии tools/install_skills.py с явно определённым каталогом скиллов. Не перезаписывай существующие навыки и не меняй чужие настройки. Инструмент установки сохраняет полный bundle и адаптирует связи с ресурсами; исходный плагин неизменён. После установки проверь обнаружение и прочитай выбранный SKILL.md.

Для совместной работы в произвольной форме выбирай offerist-assistant; для готового КП по шаблону v2 — offerist-quick; для переписки — offerist-brief; для полного исследования — offerist-seller. Настройку агентства веди через offerist-setup. Не включай конвейер автоматически при локальной правке.

Сохраняй текущий проект и приватный профиль вне исходников/установочного cache. Примеры содержат только вымышленные данные и не устанавливают реальные ставки, цели, кейсы и KPI. Не переносить их в нового клиента как факты. Не выводи секреты; используй штатные подключения и конкретный разрешённый сайт/property/counter. Бюджет платных API согласуется отдельно.

Не обещай независимое ревью при отсутствии отдельного контекста и подтверждённого вызова. Скрипты проверяют часть структуры и арифметики, не качество продажи и не пользовательскую приёмку.

При развитии комплекта запускай `python tools/validate_repository.py` и `python -m unittest discover -s tests`. Обновляй документацию вместе с изменёнными командами. В публикации допустимы исходники и синтетические примеры, а не клиентские пакеты, токены, частная переписка или история локальной рабочей папки.
