# Учебное КП для мебельного проекта

Компания «Мебельный проект», сайт `https://example.org`, агентство «Учебное агентство». Все сведения и числа специально придуманы для примера, внешние сервисы не запрашивались. Документ не является кейсом, коммерческим оффером автора репозитория или доказательством роста.

| Файл | Содержание |
|---|---|
| [brief.md](brief.md) | Задача, ограничения и выбранный SEO-охват |
| [pages.csv](pages.csv) | Шесть страниц, трафик, позиции, бизнес-приоритет и решение |
| [queries.csv](queries.csv) | Восемь запросов ядра, шесть в мониторинге и сопоставление с URL |
| [forecast.csv](forecast.csv) | Шесть периодов и три сценария; база, прирост и накопленный эффект |
| [source-ledger.md](source-ledger.md) | Происхождение всех значений, допущения и ограничения |
| [proposal.md](proposal.md) | Готовое содержание аналитического КП |
| [proposal.docx](proposal.docx) | Word с таблицами и статичными диаграммами |
| [proposal.pdf](proposal.pdf) | Просмотр результата после рендера Word |

Запрос для воспроизведения:

```text
$offerist-quick По брифу, pages.csv, queries.csv и условиям в этом примере
собери учебное SEO-КП. Не делай API-запросы. Сохрани различие данных
и сценарных допущений. GEO не включаем. Цены в примере вымышлены.
```

Содержание готового документа и цифры проверяются офлайн. Это не записанный независимый прогон агента с вердиктом клиента. Сборщик `tools/build_demo.py` воспроизводит документ и графики из учебных файлов; он не генерирует исследование нового сайта.
