# Примеры результатов специалистов

Все ситуации ниже учебные. Они показывают форму передачи; недоступный источник остаётся ограничением. Это не полный принятый workflow-пакет.

## Аудит

Сайт example.org, 6 URL из учебной таблицы. Нет GSC/Вебмастера/краула ошибок: статус unavailable для технического анализа. Данные позиций не заменяют проверку индексации. Действие: запросить разрешённые технические отчёты; не объявлять «ошибок нет».

## Аналитика

Сентябрь 2026: Яндекс 340, Google 235, сумма 575. 23 условно подтверждённых обращения в той же выборке: 4%. Определение и дедупликация из brief.md. Это учебные значения; реальные события Метрики не автоматически равны продажам.

## Конкуренты

Нет сопоставимой конкурентной выгрузки. Статус unavailable, вывод «отстаём по числу посадочных/ссылок» не сделан. Для реального результата нужны обоснованная выборка, дата, регион, источник и одинаковые определения метрик.

## GAP страниц

«Стол массив по размерам» сопоставлен с /tables/custom/: расширить существующую посадочную. «Складной деревянный стол» — кандидат нового интента, проверить линейку/спрос и отсутствие подходящей страницы. Количество запросов не равно количеству новых URL.

## GAP блоков

Пример адресного требования для /tables/: добавить выбор размера и материала с объяснением отличий. В учебном комплекте нет сохранённых HTML и peer-страниц, поэтому сравнительный диагноз pending. Не объявлять общесайтовый поблочный анализ выполненным по одной рекомендации.

## Тексты и БАР

Нет сопоставимых own/peer текстов: pending с конкретным ограничением. Отчёт и score не придуманы. Поисковая категория не получает not_applicable только из-за недоступности корпуса. Реальный запуск использует встроенный адаптер с сохранённым входом/отчётом.

## Коммерческие факторы

Кандидат улучшения: понятный выбор размера/материала и следующий шаг заказа на приоритетной категории. Проверка реального пути обращения требует просмотра страницы. Универсальный чеклист не выдаётся за наблюдение.

## GEO

В учебном запуске geo=no. Отдельный пример входа: бренд, интенты, регион, выбранные системы и реальные ответы. Выход содержит отдельно упоминание, рекомендацию и цитирование, источник/дату и действия. Без измерения baseline pending, без фиктивных скриншотов.

## Графики

В demo/proposal.docx встроены статичные графики трафика и групп из pages.csv. Подписи указывают синтетический сентябрь и единицы. График не заменяет первичный источник.

## Стратегия

Первый цикл: уточнить спрос → требования к /tables/ → согласование → публикация → контроль → сопоставимое измерение. /tables/custom/ идёт на доработку, складной интент — на проверку. Дальше живая очередь в рамках подтверждённого ресурса.

## Смета

18 часов × 2500 ₽ = 45 000 ₽; выбранный внешний фонд +10 000 ₽; всего 55 000 ₽, клиентский контент/разработка отдельно. Значения вымышлены. Нет бонуса и дополнительных гарантий.

## Клиентское ревью

Пример существенного замечания: в тексте новая страница изготовления предложена без проверки /tables/custom/. Условие исправления — сопоставить интент, изменить действие на существующей странице и обновить объём/цену. Это иллюстрация находки, не независимый вердикт модели.

## Презентация

Шесть слайдов из готового КП: текущая точка → приоритетные возможности → первые изменения → внедрение/измерение → бюджет/условия → следующий шаг. Числа, scope и ограничения совпадают с документом; презентация не добавляет новые обещания.
