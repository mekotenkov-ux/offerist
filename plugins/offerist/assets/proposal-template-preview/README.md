Эти файлы созданы до перехода на `offerist-fixed-v2` и сохранены как история визуального оформления. Они не являются эталоном текущего содержания и не подтверждают проверку новых генераторов.

Для новых КП применяются [актуальный шаблон](../proposal-template.json) и [правила авторского наполнения](../../skills/offerist-quick/references/authoring-evidence.md). Галерея v2 в этой редакции не генерировалась по поручению владельца.
