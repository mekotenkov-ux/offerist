# Графики для КП

До заголовков, подписей и выводов прочитай [правила языка и хуманизации](../offerist-quick/references/client-language.md). Они действуют внутри графиков; редактирование сохраняет названия метрик, единицы, источники и границы данных.

Этот навык строит количественные графики. Схема процесса, матрица и прототип не заменяют график с числовой шкалой и рядами данных. При доступных сопоставимых числах покажи ключевое сравнение или распределение именно графиком и встрои его в основное КП. Отсутствие истории трафика не означает отсутствие данных для графиков: можно сравнить ранжирующиеся страницы, запросы по группам позиций, проверенные группы посадочных или доноров. Для механизма работы используй отдельную схему по [референсам](../offerist-quick/references/reference-storytelling.md).

Метрика, GSC и Яндекс Вебмастер оформляются данными, графиками и таблицами. Не запрашивай браузерный вход ради их скриншотов. Эта политика действует для всех новых КП. Реальные снимки AI-ответов в GEO остаются в навыке `offerist-geo`.

Поставь вопрос графика: динамика, сравнение, распределение или состав. Выбери `line` для трёх и более временных точек, `bar` для отдельных периодов и сравнений, `hbar` для длинных названий, `stacked` для взаимоисключающих частей известного целого. Два итоговых периода — столбцы, а не выдуманная дневная динамика. Одно изолированное число можно показать текстом; несколько сопоставимых категорий уже позволяют построить диаграмму без временного ряда. Число исключённых страниц Вебмастера не называй числом ошибок.

Генератор — [scripts/charts.py](../../scripts/charts.py) от корня плагина. Python 3.10+ и Pillow; в Codex используй путь Python из `load_workspace_dependencies`. Если Pillow отсутствует, используй доступный среде рендерер по тому же контракту или установи зависимость штатным способом; не выдавай непросмотренный SVG за готовое изображение.

```text
python /absolute/plugin/scripts/charts.py --input /absolute/run/chart-spec.json --out /absolute/run/charts --name organic-visits
```

Создай JSON по [контракту](references/spec.md). Используй один показатель и единицу на график, одинаковые фильтры и сопоставимые периоды. Не соединяй clicks, visits, impressions и conversions на одной шкале. `null` означает отсутствие данных. Не выводи ноль из отсутствующей строки topN. Предварительно проверь источник, числители/знаменатели, выборку, сэмплирование и полноту. Сохранённый исходный CSV/JSON требуется вместе с SHA-256; `derivation` описывает, какие поля и преобразования использованы. Хеш подтверждает файл, а правильность выбора и преобразований проверяешь ты.

Выход — PNG для вставки в КП, SVG для редактирования и JSON-квитанция с точными рядами, метаданными и хешами. Файлы не перезаписываются. Исходники и спецификации остаются внутри рабочего запуска; клиенту выдавай только разрешённые приложения. В квитанции `evidence` исправь `path` на путь PNG относительно корня запуска перед добавлением в `evidence.json`.

Лимита точек, категорий или рядов нет. Плотные диаграммы автоматически разделяются на панели; в результате `png` — только первый лист. Прочитай `panels` и `rendered_type`, просмотри все листы, сохрани полный комплект. Для нескольких панелей, которые клиент должен видеть, добавь отдельное evidence с путём, хешем и номером каждой панели; не выдавай первый лист за всю диаграмму. В основном КП можно показать обоснованный компактный срез с явной подписью и полной таблицей в приложении: полный анализ не требует изображения каждого URL. Листы `kind: notes` сохраняют полные длинные подписи и определения.

Открой PNG и проверь русский текст, шкалы, подписи, легенду, цветовые различия и читаемость при ширине страницы. Сверь числа с исходным файлом, а не только со спецификацией. Для stacked точные части оставь в соседней таблице. TOP3, TOP5 и TOP10 вложены друг в друга: не складывай их как независимые части. Рядом с изображением в КП коротко объясни наблюдение, его границы и предлагаемое действие. Встраивай изображение, а не только ссылку; после экспорта открой страницу с графиком. Источник, период и существенные ограничения видны на самом графике. Если сопоставимых чисел нет, запиши причину в рабочих заметках и продолжай с доступной подачей; выдуманные ряды и неподкреплённый прогноз ради графической квоты недопустимы.

Стиль: белый фон, тонкая серая сетка, спокойная синяя/зелёная/оранжевая палитра, крупные подписи. Это собственная визуализация по данным сервиса; логотипы, кнопки и оболочку сервиса не воспроизводи. Не называй её скриншотом Метрики/GSC/Вебмастера. Демонстрационный режим `sample: true` явно маркирован и не создаёт наблюдаемое evidence для КП.
