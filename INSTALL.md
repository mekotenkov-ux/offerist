# Установка и перенос

## Codex

Нужен Codex с поддержкой `plugin marketplace`. Проверьте `codex plugin marketplace add --help`. Установка:

```bash
codex plugin marketplace add mekotenkov-ux/offerist --ref main
codex plugin add offerist@seomeat-offerist
codex plugin list
```

В выводе найдите установленный и включённый `offerist@seomeat-offerist`. Начните новый чат и вызовите `$offerist-assistant`. Если система показывает полное имя, выберите `offerist:offerist-assistant` в списке скиллов. [Официальная упаковка](https://developers.openai.com/plugins/build/plugins) описывает текущий формат каталогов и установки.

Для установки из скачанного репозитория вместо GitHub-источника выполните `codex plugin marketplace add ./offerist`, затем ту же команду `codex plugin add`. Запускайте первую команду из родительской папки клона.

## Другой агент со скиллами

Сначала узнайте каталог, из которого ваша среда читает SKILL.md. Единого обязательного пути для всех агентов нет. Скачать комплект:

```bash
git clone https://github.com/mekotenkov-ux/offerist.git
cd offerist
python tools/install_skills.py --destination /path/to/your/skills
```

Для отдельных скиллов:

```bash
python tools/install_skills.py --destination /path/to/your/skills --skill offerist-assistant --skill offerist-brief
```

В Windows передайте свой полный путь в кавычках. Python 3.10+ нужен только для помощников. `--dry-run` показывает план без записи. Если скилл уже существует, установка остановится до изменений; обновляйте в новый каталог или используйте штатный механизм среды после сохранения своей версии.

Инсталлятор копирует полный комплект в `destination/.offerist-bundles/<version>/` и выбранные скиллы — в `destination/<skill>/`. Ссылки на общие документы и соседние скиллы привязываются к полной копии. Это сохраняет ресурсы даже после перемещения или удаления исходного клона. Установленный каталог нельзя переносить вручную на другой компьютер: абсолютные связи нужно построить заново запуском инсталлятора.

Если агент поддерживает только плагин другого формата, используйте папку `plugins/offerist` как источник для адаптера среды. Здесь есть переносимый `plugin.json`, Codex-совместимый overlay и стандартные SKILL.md; совместимость конкретного установщика нужно проверить. Репозиторий не заявляет автоматическую поддержку любого формата плагинов.

## Агент без установки скиллов

Оставьте скачанный комплект в доступной рабочей папке и дайте агенту прочитать `plugins/offerist/skills/offerist-assistant/SKILL.md`. При другой задаче укажите соответствующий файл. Это позволяет использовать инструкции вручную, но не создаёт зарегистрированную команду и не добавляет инструменты к агенту.

## Настроить агентство

После установки вызовите `$offerist-setup` и передайте название агентства, услуги/исключения, способ внедрения, подтверждённые цены или выбор «смета для человека», KPI и допустимые кейсы. Особый формат и стиль передайте отдельным поручением. Подключение сервисов выполняйте только для нужного проекта. [Настройка](docs/training.md), [подключения](docs/connections.md).

## Обновление и проверка

Для GitHub-marketplace в Codex:

```bash
codex plugin marketplace upgrade seomeat-offerist
codex plugin add offerist@seomeat-offerist
codex plugin list
```

Приватные профили и запуски держите вне плагина, например в рабочей `.offerist`, и не коммитьте их. В ручной установке сохраните локальные изменения и устанавливайте обновление в новый каталог. Не правьте только временный cache.

Проверка скачанного комплекта: `python tools/validate_repository.py`; тесты: установите `requirements-dev.txt` и выполните `python -m unittest discover -s tests`. Проверки офлайн не подтверждают доступ к вашим API или содержательную приёмку нового КП.
