# Граф: лёгкий слой, подключаемый по необходимости

Решение 2026-09-24: обязательный Graphify в ядро не включать. Сайт [Graphify](https://graphify.com/) описывает граф кода, документов и отношений с MCP-доступом. Это возможный дополнительный способ навигации по большой базе; применимость к нашему массиву КП ещё надо проверить. Заявленные поставщиком ускорения не являются результатами теста Оффериста.

Для ядра достаточно короткой карты связей в материалах запуска:

```text
Цель клиента → наблюдение/барьер → решение → работа → KPI/срок
                                       ↘ объём/цена
Замечание пользователя → правило → область применения → проверка
```

Если портфель агентства вырастет, можно экспортировать эти сущности в JSON nodes/edges с source_id и scope, индексировать подходящим графовым инструментом и читать только относящиеся к текущему вопросу связи. Фактический источник и область агентства обязательны; граф не доказывает причинность и не должен смешивать клиентов.

Условие пилота графа: на нескольких реальных КП проверить, помогает ли он находить противоречия, повторы и подходящие правила быстрее обычного профиля и файлов. Без измеримой пользы не добавлять зависимость. Установка Graphify, индексация приватных материалов и конкретный адаптер в версии 0.1.0 не выполнялись.
