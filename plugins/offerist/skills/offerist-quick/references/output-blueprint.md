# Покрытие клиентского результата

Обязателен [общий контракт исходников и достаточности](../../offerist/references/evidence-handoff-and-depth.md): автор проверяет оригиналы, клиент получает прямые ссылки на полные выгрузки, внутренние записки не публикуются. При недостаточном основании прогноз остаётся неподготовленным; оформление не требует выдуманных данных.

В каждом аналитическом разделе обязательна последовательность **обычная подводка о том, что мы сделали, с прямыми ссылками → зелёный вывод → возможности и наши задачи → оценки и подробное доказательство с реальными примерами**. Покажи, что уже работает, где подтверждён разрыв и что осталось неизвестным. Один итоговый тезис, общие сведения о методе и список будущих работ не заменяют объяснение. Балл имеет критерии; при нехватке данных оценка ограничена явно. Ранняя сводка подготовки не отменяет эту связку внутри каждого анализа. Клиентский текст следует [правилам языка](client-language.md) и [наполнения](authoring-evidence.md), ведётся от «мы» и понятен без открытия полного анализа. Служебные хвосты «Следующий шаг»/«Источники» не выводятся.

Обязательное содержание заполняется по [фиксированному шаблону](fixed-template.md). Код задаёт римские номера с точками, порядок разделов, карточки оценок и таблицы. Не объединяй и не переставляй разделы без прямого поручения пользователя. Данные, выводы и программа индивидуальны для клиента. Подробные исследования остаются в приложениях; основные результаты, оценки и прямые ссылки сохраняются в КП.

| Раздел | Что показываем |
|---|---|
| I. Задачи и цели | С чем клиент пришёл к нам: ситуация, запрос, бизнес-задача, регион и ограничения; вопросы, на которые должно ответить КП. Наш план работ сюда не подставляется |
| I.I. Что мы проанализировали | Что проверили, фактический объём, вывод и влияние на предложение. Прямые ссылки на каждый существенный анализ |
| II. Сравнение с конкурентами | Наш сайт и сильные сопоставимые конкуренты, причина отбора и смысл метрик. Отдельные таблицы страниц/трафика, видимости Яндекса, видимости Google, ссылок/доноров/DR. Конкурентные URL — предметные примеры возможностей, без самостоятельного необъяснённого рейтинга |
| III. Состояние сайта | Сводка состояния и потенциала всех аналитических направлений, объяснение шкал и графика, наша интерпретация сильных сторон и резерва |
| III.I. Семантический охват | Внешний GAP: запросы/темы → URL конкурентов → наш URL/проверенное отсутствие → разрыв → решение. Доступные инструменты, иначе sitemap и проверенное содержание конкурентов с подписью «структурный GAP». Затем собственный инвентарь/позиционные группы, подтверждённые улучшения/создания и неизвестное. Только свои URL и запросы не закрывают раздел; первый выпуск отделён от охвата анализа |
| III.II. Текстовая релевантность | По каждой теме минимум 5 качественных рассчитанных конкурентов, предпочтительно 10; встроенный поиск полной версии БАР при доступности. В основном тексте таблицы всех участников и клиента, его место по названной метрике, вывод и изменение. Ненадёжный/малый корпус переделывается, а не легализуется оговоркой |
| III.II.I. Поведение и конверсия | Сниппеты, страницы и интент, реальные примеры, измеренные конверсии и границы |
| III.III. Техническое состояние | Краул и панели, три зоны проблем, состояние и потенциал, масштабы со знаменателями страниц и связей |
| III.IV. Доверие и коммерческие факторы | Три зоны, состояние и потенциал, сквозное доверие и посадочные в нише |
| III.V. Структура и перелинковка | Граф и поддержка приоритетных страниц; без краула явная причина отсутствия оценки |
| III.VI. Ссылочный профиль | Сила и качество: DR клиента/конкурентов через API либо публичную проверку, совместимые источник/дата/версия, таблица сравнения, реальные примеры доноров/ссылок с контекстом и атрибутами, оценка состояния по проверенному. Доноры и обоснованный темп дополняют эти выводы; один агрегат не закрывает раздел |
| III.VII. Репутация | Карты, карточки, отзывы и брендовая выдача; целесообразность SERM |
| III.VIII. Генеративный поиск | Измеренное присутствие либо пять проверенных гипотез; целесообразность GEO |
| IV. Приоритеты и стратегия | Авторский рейтинг 0–10 с основаниями и связь приоритетов с посадочными, объёмом и результатом. Рейтинг виден в КП |
| V. Модель роста | При обоснованной базе и переходах — формула, график и допущения; иначе статус неподготовленного прогноза, недостающие входы и план измерения без выдуманных чисел |
| VI. Объём работ и дорожная карта | Матрица «работы по строкам × месяцы по столбцам»; в ячейках количества или галочки; внедрения с первого месяца |
| VII. Что получает клиент | Преобразование сайта и передаваемые результаты |
| VII.I. Примеры работ | Настоящие доступные ТЗ, прототипы, отчёты и планы; фрагменты и ссылки либо причина недоступности |
| VIII. Роли и ответственность | Подтверждённая ответственность и дополнительные ресурсы; неизвестная сторона пустая |
| IX. Стоимость и бюджеты | Объёмы, внешние расходы и пустые неизвестные часы, ставки и суммы для человека |

Каждый смысловой раздел имеет понятную визуальную опору. Не придумывай данные ради графика. Схема или таблица неизвестного лучше неподтверждённых чисел. Ссылки на анализы должны открываться пользователю. Финальная проверка охватывает содержание, применимость референсов, визуальную читабельность и полный хронометраж.
