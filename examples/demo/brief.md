# Учебный бриф

Клиент — вымышленный мебельный производитель. Сайт example.org представляет столы и стулья из массива; регион Москва. Приоритет — столы из дуба и изготовление по размерам. Цель — больше подтверждённых обращений по этим направлениям, определение обращения — уникальная заявка после ручной дедупликации. Выбор для запуска: SEO, GEO не включаем.

Учебная выгрузка сентября 2026: 340 посещений из Яндекса, 235 из Google, всего 575. Условные 23 подтверждённых обращения относятся к той же выборке: наблюдаемая конверсия 4%. Позиции — одна дата 30 сентября 2026, Москва, одинаковый список шести запросов. Ядро — восемь запросов. В примере это полная заданная выборка, а не все страницы реального сайта.

Известные условия учебного агентства: 18 часов SEO в месяц по 2500 ₽, итого 45 000 ₽; внешний фонд для согласованных размещений 10 000 ₽ отдельно. Общий месячный бюджет при выборе фонда 55 000 ₽. Контент и разработка внедряются клиентом; их стоимость не определена и не включена в эту сумму. Бонус не согласован. Нет подтверждённых кейсов для вставки в предложение.

Первый цикл: дооптимизация /tables/ и проверка запуска нового интента складного стола. Публикация возможна только после готовности продуктовой линейки и контента. Дальнейшая очередь пересматривается по эффекту и внедрению, без обязательной квоты страниц каждого месяца. Прогноз — условная иллюстрация для одной когорты, не обещание результата.
