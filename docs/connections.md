# Источники подключение и инструменты

Плагин содержит инструкции и локальные помощники. Он не включает собственный обязательный MCP, API-ключи, оплаченные подписки или доступ к аккаунтам. Агент использует доступные коннекторы, браузер, файлы или инструменты своей среды. Если источника нет, его можно заменить разрешённой выгрузкой, сохранив период и охват.

## Минимальный запуск без API

Передайте бриф, сайт, выгрузки позиций/трафика, ядро и условия агентства. Этого достаточно для полезной работы, если ограничения обозначены. Быстрый режим особенно удобен, когда данные уже собраны. Недоступный технический или GEO-аудит не объявляется выполненным по одной таблице трафика.

## Локальные сборщики

В `plugins/offerist/scripts/connectors` находятся необязательные сборщики GSC, Метрики, Вебмастера, Keys.so и Ahrefs. Большинство Python-помощников используют стандартную библиотеку; GSC-мосту нужен Node.js и отдельный OAuth-клиент/токен. Посмотрите актуальные параметры:

```bash
python plugins/offerist/scripts/connectors/internal/collector.py --help
python plugins/offerist/scripts/connectors/external.py --help
```

Сначала обнаруживаются доступные свойства/счётчики, затем выбирается конкретная разрешённая цель. Используйте явные site/property/counter/host. Отсутствие строк в выбранном отчёте не доказывает отсутствие трафика всего сайта. GSC базового поискового сбора не заменяет все технические отчёты индексации.

Точные переменные, параметры, пагинация и статусы описаны в [руководстве сборщиков](../plugins/offerist/docs/connectors.md). Ключи передаются существующим защищённым подключением, отдельным приватным файлом или переменной текущего процесса, а не записываются в скилл/репозиторий. Локальный реестр подключения, если он есть в системе пользователя, читается по действующим AGENTS-инструкциям этой системы; чужие абсолютные пути не копируются.

## GA4 и другие средства

В комплекте нет отдельного GA4-моста. Используйте доступный GA4-коннектор, собственный read-only инструмент или экспорт. Не выводите property из GSC-домена автоматически. Цель аналитики не обязательно равна квалифицированному обращению или продаже — определение должно быть подтверждено.

Screaming Frog подключается через разрешённые экспорт/краул. Keys.so и Ahrefs требуют своих условий доступа; большие выгрузки по умолчанию не запускаются. Для Ahrefs согласуется бюджет запросов, кэш и журнал сохраняются между повторами, неизвестная тарификация обозначается. Встроенный БАР выполняет статистическую текстовую проверку только при доказанной применимости и реальных сопоставимых текстах.

GEO требует реального измерения ответов выбранных систем. Без браузера/подходящего инструмента можно составить план измерения и пометить baseline как ожидающий, но нельзя нарисовать фиктивные ответы. Доступ к ChatGPT или поисковику в одной среде не распространяется на агент другого пользователя.

## Оформление и независимое ревью

Для графиков встроенный `charts.py` формирует статичный результат из проверенных данных; PNG зависит от Pillow. Word/XLSX/PDF и презентации создаются инструментами среды или установленными библиотеками. Рендер требует доступного конвертера или Word. Учебный Word/PDF уже лежит в примерах; генератор примера использует python-docx и Pillow с доступным шрифтом кириллицы.

Независимое ревью требует отдельного чистого контекста и фактического вызова. Если среда не умеет делегировать, подготовьте пакет и запустите reviewer в другом чате. Самопроверка автора не называется независимой. Это различие сохраняется в статусе готовности.
